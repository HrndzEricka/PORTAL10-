2. Explique la diferencia entre una pila (LIFO) y una cola (FIFO), dando un ejemplo cotidiano de cada una. 15 pts
Una pila (LIFO, Last In First Out) hace que el último elemento en entrar sea el primero en salir, como una pila de platos: se saca primero el de arriba. Una cola (FIFO, First In First Out) hace que el primer elemento en entrar sea el primero en salir, como una fila para comprar entradas: el primero que llega es atendido primero.
